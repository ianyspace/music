## 1. 背景与目标

### 1.1 决策变更（相对 v0.1）

用户已拍板：

1. **默认星云**：星云模式是产品的默认形态，自定义背景是可选项，不是对等双模式。
2. **旧 PC 功能全部退役**：不做「沉浸模式开关」，重做后的页面**就是** PC 端页面。现有三栏工作区、左侧完整歌单列表、顶部栏、右上角立方体设置入口等一并移除，不做兼容保留。
3. **底部播放栏常驻**：不自动隐藏，永远可见。
4. **歌单在左侧，3D 呈现，可自动收起**：对齐参考图 A 的左侧悬浮卡形态，收起后留一个唤出把手。

### 1.2 目标形态

对齐两张参考图：

- **参考图 A（星云 · 默认）**：全屏 3D 粒子星云（封面粒子化，占满整屏、有景深），UI 全部悬浮为玻璃卡片——左侧 3D 歌单、底部玻璃播放条、歌词居中。
- **参考图 B（自定义背景 · 可选）**：全屏视频/动图/图片背景，歌词居中大字，底部同款播放条。

### 1.3 非目标

- 不改移动端（h5）任何行为。
- 不改播放内核（`usePlayer` / `PlayerAudio`）、曲库来源、QQ 登录逻辑。
- 不做歌词翻译/罗马音等新数据能力（仅升级呈现）。

## 2. 页面整体结构（重做后，即 PC 端唯一形态）

```
┌───────────────────────────────────────────────────┐
│  L1 背景层   WebGL 全屏 canvas（星云 / 自定义背景）   │
│                                                   │
│  ┌────────┐        ┌──────────────┐               │
│  │ 歌单面板 │        │   歌词（DOM） │               │
│  │ (左侧,  │        │   居中大字    │               │
│  │  可收起) │        └──────────────┘               │
│  └────────┘                                       │
│  ▸ (收起后的唤出把手)                               │
│        ┌───────────── 底部播放栏（常驻）─────────┐   │
│        └──────────────────────────────────────┘   │

```

| 层 | 实现 | 说明 |
|---|---|---|
| L1 背景层 | three.js（动态加载），全屏 canvas | 默认 `NebulaProvider`；可选 `MediaProvider`（视频/图/动图） |
| L2 歌词层 | DOM（CSS 3D + 滤镜） | 保留可选中、可读屏 |
| L3 悬浮 UI | DOM（毛玻璃） | 左侧歌单面板、底部播放栏、设置弹层 |

## 3. 默认模式：星云（对标参考图 A）

### 3.1 视觉

- 当前歌曲封面粒子化为**占满视口的 3D 星云**：粒子 6~10 万、前中后三景深、雾气与辉光后处理；粒子色取自封面像素，深色底。
- 音频联动（复用现有 `audioAnalyser` 链路）：
  - 低频：星云整体膨胀/收缩；
  - 中频：粒子流速与雾气浓度；
  - 高频：局部星点闪烁；
  - 节拍：冲击波沿 Z 轴推进。
- 暂停：缓慢漂浮（呼吸态）；切歌：散开重组。

### 3.2 首次进入

- 页面加载即进入星云模式（无需任何开关操作）；设置里可切到自定义背景，切回同样一步。

### 3.3 粒子源（已拍板）

- 首版**只用当前歌曲封面**，不做艺人照片等新图源。

---

## 4. 可选模式：自定义背景（对标参考图 B）

### 4.1 背景源（已拍板）

- **预设库**：首版只内置 **1 个**简单预设（一段免版权氛围视频，R2 托管），验证链路后视需要再扩。
- **自定义**：粘贴视频/图片直链 URL 存入「我的背景」（localStorage），可删除；**不做本地上传**。
- 统一抽象为 `BackgroundProvider`（nebula / video / image / gif），切换交叉淡入无白屏。

### 4.2 视频背景策略

- 循环、静音、`playsInline`，可压速 0.8×。
- 自动叠加可读性滤镜（压暗 + 渐晕，强度可调），保证白字歌词可读。
- 无音频联动，但歌词换行仍有轻量动效（§6）。
- 加载失败降级为封面模糊静态图。

## 5. 悬浮 UI

| 组件 | 位置 | 行为 |
|---|---|---|
| **3D 歌单面板** | **左侧**，悬浮玻璃卡 | 展示**当前歌单**（不做其他歌单切换）：歌单封面 + 名称 + 歌曲列表（滚动）；列表项悬浮有 3D 倾斜/景深反馈（CSS 3D，非 WebGL）；点击切歌 |
| 面板自动收起 | 左侧 | 鼠标离开面板区域 5s → 面板滑出至屏幕左缘，留一个竖条把手（封面色渐变 + 当前播放指示条）；点击把手或鼠标移至左缘唤出；播放暂停时不收起 |
| **底部播放栏** | 底部居中，玻璃胶囊，**常驻不隐藏** | 封面缩略图、歌名/歌手、喜欢、上一首/播放/下一首、词开关、进度与时间、音量、全屏 |
| 设置入口 | 播放栏内齿轮 | 弹出面板：背景模式（星云/自定义+素材选择）、星云强度、可读性滤镜、歌单自动收起开关 |
| 全屏 | 播放栏内 | Fullscreen API |

自动收起的例外规则：鼠标悬停在面板上、播放暂停、用户刚完成一次切歌（3s 内），均不收起。

## 6. 歌词层

- 位置：视口居中，两模式都显示（星云模式可在设置里关，纯享星云）。
- 样式：当前行大字号（约视口高 4%）白色 + 柔投影；上下行半透明小字；更远行淡出。
- 逐字渐变：有逐字时间轴则逐字扫过，否则按行时长匀速。
- 换行动效：旧行上浮淡出、新行就位；星云模式同时触发一次星云冲击波，让词与画面咬合。
- **节奏联动（本轮新增，已拍板）**：歌词必须能"感觉到音乐"——
  - **节拍脉冲**：检测到节拍时，当前歌词行做一次轻微的缩放/亮度脉冲（幅度克制，约 1.03~1.06 倍，随强度档位），连续节拍下呈现"随鼓点呼吸"的效果；
  - **响度呼吸**：当前行文字亮度/辉光随实时响度浮动，安静段收、高潮段亮；
  - **换行对拍**：换行动效的时长贴合歌曲 BPM 感（快歌干脆、慢歌绵长），避免快歌时动画还没放完下一行就来了；
  - 实现上全部复用 `audioAnalyser` 的低频/响度采样，节拍检测与星云共用同一份检测结果，不重复计算。
- 交互：点击歌词区 = 播放/暂停；滚轮翻看完整歌词，停止 3s 回到跟随。

## 6.5 全局过渡动画规范（本轮新增，已拍板）

所有过渡动画必须丝滑顺畅、因果合理，统一遵守：

1. **统一时长体系**：微交互 150–200ms、面板进出 300–400ms、场景级切换 600–800ms；同一类交互全站时长一致，不各自为政。
2. **统一缓动**：面板/浮层用 `cubic-bezier(0.32, 0.72, 0, 1)`（标准"玻璃滑入"曲线）；内容淡入淡出用 ease-out；**禁用 ease-in-out 线性感**和生硬的 linear。
3. **GPU 合成优先**：所有动画只动 `transform` / `opacity` / `filter`，禁用触发 reflow 的属性（width/height/top/left）；大量 DOM 动画加 `will-change` 并在动画结束移除。
4. **交叉淡入**：任何"消失+出现"（切歌封面、背景模式切换、面板收展）一律新旧交叉淡入，不允许白屏/闪跳。
5. **因果与方向**：动画方向表达空间关系——歌单从左缘滑入滑出、设置从播放栏弹出、歌词行向上流动；元素去哪就从哪个方向走，不凭空缩放消失。
6. **可中断**：动画进行中再次触发时从当前状态平滑接管（CSS transition 天然支持，JS 驱动的节拍脉冲需做插值衔接），不允许跳变或排队卡顿。
7. **性能红线**：动画期间掉帧即降级——节拍脉冲等非必要动效在检测到帧率低于 45fps 时自动减弱（复用强度档位思路）。

## 9. 技术方案

1. **three.js（动态加载）**：`next/dynamic` + `ssr:false`，仅沉浸层使用；静态导出兼容按需 chunk；普通/h5 页面 0 体积影响，沉浸页激活后约 +150KB gz。
2. **场景架构**：`ImmersiveStage`（场景管理器：canvas、rAF、资源生命周期、WebGL 上下文丢失恢复）+ Provider 体系：
   - `NebulaProvider`：CoverParticles 管线升级（2 万→6~10 万粒子、Z 轴景深、雾与辉光后处理）；
   - `MediaProvider`：`VideoTexture`/图片纹理全屏面片 + 可读性滤镜着色器。
3. **页面骨架**：`pages/desktop` 直接渲染新组件族 `ImmersiveApp`（舞台 + 歌单面板 + 播放栏 + 歌词），旧 `DesktopMusic` 组件树退役删除。
4. **不动清单**：`usePlayer`、`PlayerAudio`、`audioAnalyser`、`librarySource`、曲库/歌单状态、h5 全部。
5. **性能护栏**：页面不可见暂停 rAF 与视频；粒子数随屏幕尺寸自适应；强度档位。

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| 旧页面直接退役，用户习惯断层 | 播放内核与歌单逻辑不变，操作心智（点击切歌、进度拖动）全部延续 |
| 内置视频素材体积与版权 | 只用免版权素材（Pexels 等），R2 存 720p/1080p H.264/H.265 双份，按需加载 |
| three.js 体积 | 动态加载仅沉浸页；其他页面 0 影响 |
| 自定义 URL 跨域/失效 | video 标签天然容忍跨域；失败降级封面模糊图并提示 |
| 大粒子规模压力 | PC-only + 粒子数自适应 + 强度档位 + 页面隐藏暂停 |
| 歌单面板收起后可发现性 | 把手带当前播放指示条常亮；设置里可关闭自动收起 |
